# Task Completion Workflow

When a task, sprint, or major milestone is completed, follow these steps to ensure the workspace remains organized and the context is preserved.

## 1. Execute Clark Skill
Call the `clark` skill to synchronize the project's memory files.

1. **Review**: Analyze the work done in the current session.
2. **Log**: Update `00_Context/Memory/decisions_log.md` with any new decisions.
3. **Status**: Update `00_Context/Memory/state_of_play.md` with the current build state.
4. **Tasks**: Mark progress in `00_Context/Memory/project_tasks.md`.
5. **Clean**: Perform memory hygiene in `00_Context/Memory`.

## 2. Verify Documentation
Ensure any new code is properly documented and that any relevant technical specs are updated if the changes were structural.

## 3. Final Report
Provide a concise summary of what was accomplished and what the user should focus on next.
