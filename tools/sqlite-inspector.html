SQLite Inspector

Open a local SQLite file and inspect tables in-browser. This stays client-side after the page and WebAssembly runtime load. Useful targets in this repo include storage/kernel_registry.sqlite and any memory.sqlite file under storage/agents/. If the live DB looks empty, create a merged snapshot first with tools/sqlite-snapshot.sh storage/kernel_registry.sqlite and open the snapshot file instead.
